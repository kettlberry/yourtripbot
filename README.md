# YourTripBot — n8n Workflow

Набор workflow для MVP Telegram-бота туристической компании, реализованного в n8n.

Бот консультирует пользователей по экскурсиям и турам, обрабатывает текстовые и голосовые сообщения, использует RAG-поиск по базе знаний, помогает оформить заявку и поддерживает сценарий оплаты.

## Архитектура

Основной поток:

`Telegram → n8n → AI Agent → Supabase Vector Store / RAG → OpenAI → Telegram`

Дополнительно используются:

* Google Sheets — хранение заявок и статусов оплаты;
* PostgreSQL — память диалога;
* OpenAI Speech-to-Text — обработка голосовых сообщений;
* Telegram Bot API — интерфейс взаимодействия с пользователем;
* webhook — обработка информации об оплате.

## Workflow

### `Booking Flow MVP Template.json`

Основной workflow Telegram-бота.

Отвечает за:

* получение сообщений из Telegram;
* определение текстового или голосового ввода;
* транскрибацию голосовых сообщений;
* работу AI Agent;
* использование памяти диалога;
* поиск информации через Supabase Vector Store;
* генерацию ответа;
* запуск сценария бронирования;
* отправку ответа пользователю.

### `Booking Tool.json`

Workflow оформления заявки.

Функции:

* получение данных клиента;
* создание заявки;
* запись данных в Google Sheets;
* сохранение стоимости и статуса заявки;
* отправка уведомления о новой заявке;
* формирование ссылки на оплату.

### `Payment Check.json`

Workflow обработки оплаты.

Функции:

* получение данных через webhook;
* поиск заявки в Google Sheets;
* проверка оплаченной суммы;
* определение полной или частичной оплаты;
* обновление статуса заявки;
* уведомление пользователя;
* формирование ссылки для доплаты при необходимости.

### `Typing Loop.json`

Вспомогательный workflow для улучшения UX.

Периодически отправляет Telegram-событие `typing`, пока основной workflow формирует ответ.

## Используемые технологии

* n8n
* Telegram Bot API
* OpenAI
* Supabase Vector Store
* PostgreSQL
* Google Sheets
* RAG / Semantic Retrieval
* Speech-to-Text
* Webhooks

## Назначение проекта

Проект создан как MVP автоматизированного AI-консультанта для туристической компании.

Основная идея — объединить консультацию, поиск информации о туристических продуктах, оформление заявки и обработку оплаты в одном Telegram-интерфейсе.
